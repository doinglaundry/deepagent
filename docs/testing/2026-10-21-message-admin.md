## Chrome 端到端集成

实际启动 Go Web、Go Worker、MySQL、Redis 和 Google Chrome，仅模型 HTTP 使用受控响应以稳定复现异常。最终仓库代码构建的二进制在独立空库通过以下九组：

1. 空状态与内嵌资源加载。
2. 原页面提交 → Worker → 模型 HTTP → 文件工具 → 持久化 → 后台查询；核对模型请求上下文、工具定义、完整输出与原始分片。
3. 类型过滤、工具参数/结果展开、长 ID 复制、JSON 导出、中英切换。
4. 执行 ID 查询、消息 ID 定位与附近上下文。
5. ask_user 暂停、重启 Worker、原 Run 续跑；中断与恢复输入可查。
6. 实际创建子任务、父子范围隔离、包含子任务及最近查询恢复范围。
7. 模型 HTTP 失败可追踪、缺失 ID、错误提示。
8. 105 条待处理输入、两页追加、无 Run 输入、最近查询持久化、用户文本防注入。
9. 断网后的提示和重试；无浏览器运行时异常。
