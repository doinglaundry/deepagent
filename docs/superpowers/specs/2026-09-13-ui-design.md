# DeepAgent UI 方案

## 页面

```text
App
├── ThreadList
├── Conversation (MessageList, ToolCallCard, Composer)
└── RunPanel (Status, ApprovalCard, EventLog)
```

## 类型

```ts
type SubmitTaskRequest = { threadID?: string; input: string }
type RunEvent = { eventID: string; threadID: string; runID: string; sequence: number; type: string; payload: unknown }
type ApprovalDecision = { approvalID: string; approved: boolean }
```

## 事件

```text
run.started | llm.delta | tool.started | tool.completed
approval.required | context.compacted | run.completed | run.failed
```

```text
UI → Manager API → queued → Worker → Thread → Core
submit → queued → running → events → completed/failed
cancel → Manager → Worker → Thread cancel
resume → checkpoint → new run
```

## 风格

```text
dark workspace; blue=running; orange=approval; red=denied/failed
tool output collapsed by default
```
